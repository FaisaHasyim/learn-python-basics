# Learn Python Basics

Repository ini berisi latihan dasar pemrograman Python yang fokus pada logika komputasional dan penerapan algoritma sederhana. Setiap program dirancang dengan pendekatan flowchart dan pseudocode sebelum implementasi.

## 📚 Konten Project

### Problem 1: Hitung Kuadrat dari Bilangan
**File:** `problem_1.py`

Menghitung kuadrat dari bilangan yang diinput user.

**Konsep:**
- Input/Output
- Operasi aritmatika (perkalian)
- String formatting dengan f-string

**Cara menjalankan:**
```bash
python problem_1.py
```

**Contoh output:**
```
Masukkan bilangan: 5
Kuadrat dari 5 adalah 25
```

---

### Problem 2: Cari Bilangan Terbesar dari 3 Bilangan
**File:** `problem_2.py`

Membandingkan 3 bilangan dan menemukan nilai terbesar di antaranya.

**Konsep:**
- Input multiple data
- Percabangan (if-elif-else)
- Operator logika (and, or)
- Conditional logic

**Cara menjalankan:**
```bash
python problem_2.py
```

**Contoh output:**
```
Masukkan bilangan pertama: 10
Masukkan bilangan kedua: 25
Masukkan bilangan ketiga: 15
Bilangan terbesar dari 10, 25, 15 adalah 25
```

---

### Problem 3: Sistem Grade Siswa
**File:** `problem_3.py`

Menentukan grade (A/B/C/D) berdasarkan nilai yang diinput.

**Konsep:**
- Input processing
- Multi-level conditional (if-elif-else)
- Pengambilan keputusan berdasarkan kriteria
- Output formatted

**Kriteria Grade:**
- A: nilai ≥ 80
- B: nilai ≥ 70 dan < 80
- C: nilai ≥ 60 dan < 70
- D: nilai < 60

**Cara menjalankan:**
```bash
python problem_3.py
```

**Contoh output:**
```
Masukkan nama siswa: Faisa
Masukkan nilai: 85
Faisa mendapatkan grade A
```

## 💡 Tips untuk Belajar

1. **Pahami logika sebelum coding** — Buat flowchart dulu, jangan langsung kode
2. **Test dengan berbagai input** — Coba edge case (nilai terbatas, negatif, dll)
3. **Eksperimen** — Modifikasi program, tambah fitur baru
4. **Commit secara teratur** — Setiap kali ada perubahan penting
5. **Dokumentasi** — Tulis komentar yang jelas di code
